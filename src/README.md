# Обработка оптовой заявки

Python 3.10+; внешние зависимости не нужны.

Из папки `src` запустите:

```sh
python3 main.py example.json
```

Входной файл `example.json` содержит покупателя, каталог с ценами в рублях,
физические остатки, активные резервы и подтверждённую заявку. Ожидаемый вывод:

```json
{
  "status": "reserved",
  "request_id": "R1",
  "total": "33500.00"
}
```

Если товара не хватает, программа выводит `shortages`; если сумма изменилась,
запрос возвращается на согласование. Резерв создаётся целиком только после
повторной проверки. Изменения живут в памяти одного запуска, поэтому программа
не обеспечивает защиту от одновременных процессов и не заменяет транзакцию СУБД.

Для отмены уже зарезервированного заказа запустите:

```sh
python3 main.py example_cancel.json
```

Поле `operation` равно `cancel`, а `cancellation` содержит номер заявки и
непустую причину. Программа снимает все активные резервы этой заявки, записывает
причину в заявку и возвращает `status: cancelled`. Повторная отмена отклоняется.
Физические остатки не меняются.

Ожидаемый вывод для `example_cancel.json`:

```json
{
  "status": "cancelled",
  "request_id": "R1",
  "reason": "Покупатель отказался от заказа",
  "released_reservations": 2
}
```
